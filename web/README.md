# web/ — the only real-money surface

Canon §1: the marketplace is **web-only** — never inside the mobile apps (app-store
policy) — and gated behind 18+ CPF-grade age verification (legal launch blocker,
docs/business/30).

- `marketplace/` — listings, escrow status, price history, buy/sell (Phase A:
  closed-loop credit; Phase B: Pix cash-out after the legal parecer).
- `account/` — account portal, age verification, seller onboarding (KYC via PSP).
