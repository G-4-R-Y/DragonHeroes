# Modern pixel-art direction candidates

Created with the built-in `image_gen` tool for this review branch. The tool
did not expose a model identifier. These are candidates, not approved game
assets; existing repository asset licensing applies.

- [Gloamfen target](gloamfen-target.png): generated scene concept, not a
  capture of the running game. Exact generation [prompt](prompt.txt).
- [Bellwether source](../../../genforge/art_sources/bellwether/source.png):
  eight-frame idle candidate. Exact generation
  [prompt](../../../genforge/art_sources/bellwether/prompt.txt).

Run `python3 tools/review_living.py` from the repository root to build the
palette-constrained 128px atlas, emissive mask and interactive review. The
manifest records source hashes and declared provider provenance. No production
approval, motion/contact pass or mobile performance claim is implied.
